Comment ajouter un cours ?

1. Ouvre ce fichier dans Notepad / VS Code.
2. Cherche const COURS en bas du fichier.
3. Copie un bloc cours, change classe, matiere, sous, titre, objectif, contenu.
4. Enregistre et actualise la page. Même logique pour EXERCICES, DEVOIRS, TP.

{classe:1, matiere:"Math", sous:"Numération", titre:"Les nombres de 0 à 10", objectif:"...", contenu:"...", exemples:"...", retenir:"..."}
